# 録音の告知について

文字起こしちゃんは、Web会議を検知すると自動で録音を始めます。録音や文字起こしをするときは、参加者へ事前に伝えてください。

- 社内の会議では、議事録のために録音していることをチームへ一度伝えておくと、毎回断らずに済みます。
- 社外の方との会議では、冒頭で「議事録用に文字起こしを取っています」と一言伝えてください。秘密保持契約や先方の方針で、録音や記録の作成が認められていない場合があります。
- 伝えられなかった会議の記録は、自分のメモとしてだけ使い、共有や転記をしないでください。
- 国や地域によっては、録音に参加者全員の同意を求める法律があります。海外の方が参加する会議では特に注意してください。

録音・文字起こし・要約はすべてMacの中で処理され、外部のサーバーへは送りません。保存先は [動作の詳細](behavior.md#保存されるもの) を参照してください。

初めて起動したときに、この内容を確認する画面を一度だけ表示します。
